# 松宮工材 容器管理システム

容器の入荷・納品・回収、貸出期間に基づく使用料計算を扱うMVPです。

## セットアップ

1. Supabaseプロジェクトに `supabase/migrations/202610160001_container_lifecycle.sql` を適用します。
2. `.env.example` を `.env.local` にコピーし、値を設定します。
3. `npm install` 後、`npm run dev` を実行します。

## 使用料ルール

- 納品日から93日間は無料（納品日・回収日ともに日数へ含める）
- 94日目から31日あたり600円
- 月ごとに `floor(日数 × 600 / 31)` 円で切り捨て
- 同じ貸出・対象月は一度だけ計算可能

ライフサイクルの状態遷移と監査履歴は、クライアントではなくDB関数で一括して確定します。
